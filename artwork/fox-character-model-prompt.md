# Fox character model

Created with the built-in image-generation tool using the fox image supplied
in the project conversation as the edit reference. The transparent PNG is the
approved character model. The game renders this bitmap and its matching pose
sheets directly at high detail, rather than redrawing it on a smaller grid.

Prompt used:

> Use case: style-transfer. Asset type: fox character model for the Lil Buddy desktop pet game. Edit the supplied fox image into a polished, crisp pixel-art fox character on a genuinely transparent background. Keep the reference character's warm golden-orange/russet coat, sweet dark purple glossy eyes, upright large pointed ears, tapered muzzle, tall seated pose, and especially its enormous plush curved tail sweeping upward with a tapered tip. Make its anatomy recognizably fox-like: a visible pointed black nose, cream cheek ruff and bib, small darker paws, and cream-white brush tip. The tail may curl behind the character to the left so the face points right; keep the original elegant curved silhouette and friendly expression. Remove the cream card, rounded border, and floating purple star shapes. One complete seated fox, facing right in a clear side / slight three-quarter view, centered with a little transparent padding, fully visible ears, paws, and tail. Handcrafted 16-bit pixel art with a controlled warm palette, clean pixel clusters and stepped contours, no blur, no antialiasing, no scattered noise, no text, no watermark. It should look like an actual 60x48 game sprite enlarged with nearest-neighbor pixels, with a readable silhouette and simple expressive face. No cat anatomy, no vector smooth edges.
