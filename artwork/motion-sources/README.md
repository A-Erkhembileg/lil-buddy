# Animation source artwork

These sheets were created with the built-in image-generation tool from the approved character models. Each sheet contains sixteen poses in a four-by-four grid. The runtime uses registered atlases in `artwork/motion/`; regenerate those with `tools/bake_motion_atlases.py`.

Walking sheets contain a sixteen-pose cycle. Reaction sheets contain four idle, six petting, and six airborne poses. Original Cat, Husky, and Fox faces, coat details, and proportions are retained. A Fox candidate that included sitting poses in the walk was rejected and replaced.

## Prompts used

### cat walk

Use case: identity-preserve. Production animation sprite sheet for Lil Buddy. Reference image is the LOCKED CHARACTER MODEL: the exact approved orange tabby CAT: green eyes, white muzzle/chest/paw tips, orange stripes, round friendly feline head, fluffy curved white-tipped tail. Preserve the reference's exact detailed pixel-art style, face, coat, eye color, head proportions, tail shape and volume; no character redesign or simplified tiny sprite. EXACTLY SIXTEEN equally sized cells in a strict 4-column by 4-row grid, read left to right then top to bottom. One complete animal per cell, consistently facing RIGHT with the same side / slight three-quarter camera, the SAME scale and torso/head position. Maintain a consistent floor baseline and stable nose/chest anchors. Every ear, nose, paw, and tail fits fully INSIDE its cell with generous transparent padding; no overlap with adjacent cells. Genuinely transparent background: no backdrop, shadows, glow, labels, numbering, grid lines, scenery, hearts, stars, blur, or motion trails. Target a 2048x2048 sheet with 512x512 cells. Draw one coherent SIXTEEN-FRAME graceful walking cycle. Frames 1-16 are consecutive evenly spaced moments of a SINGLE step cycle that loops seamlessly back to frame 1. Anatomically correct four-legged walking: alternating front and rear contacts, down/passing/up/return poses, paws gradually advancing every frame, planted support paws, soft elbows/knees/hocks. No duplicated static stance frames. Small consistent head/body bob and gentle secondary tail follow-through, with no size changes, no exaggerated bouncing or running, no turning. Keep the torso level and reference identity constant. Natural dignified motion at the supplied model's full detail.
